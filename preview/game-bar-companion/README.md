# Game Bar companion

This optional x64 UWP widget is the only packaged component in the project. The primary Tauri application remains unpackaged Win32 software delivered by NSIS.

The widget requires Windows 10 2004 (build 19041) or newer and Xbox Game Bar. It connects as a client to `\\.\pipe\LOCAL\AchievementWatcher.GameBar.v1`, authenticates using the 256-bit token generated by the desktop app, and acknowledges a notification only after Game Bar accepts it. The pipe DACL permits AppContainer access, while the token prevents another local process from impersonating the paired widget. No network capability or listening port is used.

`build-sideload.ps1` creates an uncommitted self-signed code-signing certificate and x64 package. `install-sideload.ps1` trusts that exact public certificate for the current user before installing the selected package. To remove both package and trust entry:

```powershell
./uninstall-sideload.ps1 -CertificatePath ./AchievementWatcher.GameBar.cer
```

Never distribute the generated `.pfx`; release automation should protect the signing key and distribute only the `.appx`/`.msix` and `.cer` files.
